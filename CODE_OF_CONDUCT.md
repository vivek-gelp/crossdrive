# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
by reference. In short: be respectful, assume good faith, keep feedback about the work and not the person, and do not
harass anyone.

Report conduct problems privately by opening a GitHub Security Advisory draft on this repository and marking it as a
conduct report, or by contacting a maintainer through their GitHub profile. Maintainers may remove comments, close
issues and block participants who break these rules.
