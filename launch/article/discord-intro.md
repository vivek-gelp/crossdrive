Hi all, I built Crossdrive, a self-hosted remote MCP server that gives Claude (or any MCP client with OAuth) one URL onto several Google Drive and Gmail accounts, with trash-only delete, draft-only mail by default and per-account read-only mode enforced in code. I also wrote up four ways to work with several Google accounts in Claude, including two that need no new software, plus what to insist on from any tool that touches your files: https://vivek-gelp.github.io/crossdrive/blog/several-google-accounts-with-claude.html It is MIT licensed, OneDrive and Dropbox are still beta and untested live, and if you try it and get stuck I am happy to help here or in a GitHub issue.
